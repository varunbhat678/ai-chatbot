# AI Chatbot

AI-powered chatbot built with FastAPI, PostgreSQL, OpenRouter, JWT authentication, chat sessions, PDF document upload, and RAG-based question answering.

## 🚧 Project Status

Currently under active development. Additional features, testing, and deployment are in progress.

## Current Features

- User registration and login
- JWT authentication
- AI chatbot using OpenRouter
- Multiple chat sessions
- PostgreSQL database
- PDF document upload
- RAG-based question answering
- HTML/CSS/JavaScript frontend

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- OpenRouter
- JWT
- RAG
- FAISS
- PyPDF
- HTML
